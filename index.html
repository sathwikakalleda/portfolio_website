Automobile EDA — Pricing & Performance

Kaggle Dataset · 205 Automobiles · 26 Features

Problem Statement

Understand how vehicle specifications influence pricing, performance, and fuel efficiency. The analysis aims to identify the key factors that drive automobile prices and uncover patterns in the dataset.

Approach

  • Data Inspection: Reviewed shape, data types, and summary statistics; identified missing values and incorrect formats.
  • Data Cleaning: Handled missing values via mean/median/mode imputation; standardized features for analysis.
  • Univariate Analysis: Analyzed distributions of price, engine size, horsepower; identified skewness and outliers.
  • Bivariate Analysis: Explored price relationships with engine size, horsepower, curb weight, and fuel type via scatter and box plots.
  • Multivariate Analysis: Created a correlation heatmap to identify strong predictors of price.
205Records
26Features
4Key Insights

Key Insights

  • Engine size, horsepower, and curb weight show strong positive correlation with price.
  • Mileage has a negative relationship with price.
  • Fuel type and body style significantly impact price distribution.
  • Higher performance vehicles are generally priced higher across all segments.

UAE Banking Data Analysis

Retail Banking SQL Portfolio · BI-Ready Star Schema

Problem Statement

Simulate a UAE retail banking environment to demonstrate structured SQL-based analysis — monitoring operational KPIs, generating MIS reports, analysing branch performance, and evaluating customer risk exposure to support data-driven decision-making.

Approach

  • Data Modelling: Designed a Star Schema with Customers & Branches (dimensions) and Accounts & Transactions (facts); validated referential integrity across all relationships.
  • SQL Analysis: Used CTEs, Window Functions, Joins, and Aggregations for KPI reporting and segmentation.
  • MIS Reporting: Built monthly transaction trend reports, branch performance scorecards, and credit vs debit liquidity analysis.
  • Compliance: Structured compliance-ready queries for audit monitoring and customer risk evaluation.
